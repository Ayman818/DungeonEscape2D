# Dungeon Escape 2D

## SWE402 — Assignment 2

**Chosen Option:** Option 1 — 2D Roguelike Game

**Unity Version:** 6000.5.11f1

## Game Description

Dungeon Escape 2D is a turn-based roguelike game developed with Unity. The player explores procedurally generated desert-themed dungeon levels, collects food to survive, fights enemies, destroys obstacles, and finds the exit to progress.

## Controls

| Key | Action |
|---|---|
| Arrow Keys | Move and attack |
| ESC | Pause or resume |
| R | Restart after Game Over |

## Features

- Procedural dungeon generation
- Turn-based player movement and enemy AI
- Food collection and survival system
- Destructible walls and enemy combat
- Smooth movement and sprite animations
- Background music and sound effects
- Particle effects and particle pooling
- Level progression with increasing enemy counts
- Main Menu and Pause Menu
- Game Over and Restart

## Bonus Features

- **Dynamic Board Scaling:** Enemy count increases as the player advances through levels.
- **Main Menu & Pause Menu:** Play, Quit, Resume, and Restart functionality.

## How to Run in Unity

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add project from disk** and choose the project directory.
4. Open the project using Unity 6000.5.11f1.
5. Open `GameScene` from the Assets folder.
6. Press Play.

## Windows Build

The Windows standalone build has been created and tested.

To run it, download the complete Windows build, extract all files, and launch `DungeonEscape2D.exe`.

The executable must remain alongside its `_Data` folder and supporting Unity files.
